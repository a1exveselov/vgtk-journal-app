# VGTK: пробное делегирование OpenCode v2
Пакет не изменяет приложение и не устанавливает зависимости. Требуется Node.js и рабочий OpenCode CLI (проверялся пользователем на версии 2.4.1).

## Установка
1. Распаковать в корень F:\elJournal\el-journal с сохранением каталогов `.agents` и `tools`. Не перезаписывать существующие файлы при конфликте. `AGENTS-AI-ADDENDUM.md` — дополнение, вручную перенести в конец существующего AGENTS.md только после теста. Никаких изменений в src.
2. Перед запуском проверить https://opencode.ai/docs/console/models/ — обе модели должны быть Free по входу и выходу; использовать бесплатный режим без подключённого платного биллинга. --free-confirmed не проверяет тариф автоматически и не является финансовой гарантией. Если тариф изменился, не запускать.
3. В PowerShell из корня проекта: `node tools/ai/delegate.mjs deepseek --smoke --free-confirmed`. Ожидается код sum. При необходимости отдельно протестировать hy4 той же командой с hy4 вместо deepseek. При ошибке не отключать запреты, прислать диагностику без секретов.
4. Проверить настройки OpenCode на наличие глобальных/управляемых разрешений, внешних плагинов и платного аккаунта. Политики из более приоритетных конфигураций могут переопределять локальные. Перед передачей исходников отдельно проверить эффективные политики; до этого только искусственные запросы. Изоляция временной папки не равна ОС-песочнице. OpenCode может сохранять историю сессий вне временной папки, даже после её очистки.
5. При успехе добавить дополнение в AGENTS.md, открыть новую сессию Codex. Пример: `Используй $delegate-task только для синтетической проверки шлюза, без чтения src и без изменений приложения. Подтверждаю бесплатные DeepSeek и Hy4 для этой сессии. Выполни один smoke-тест и сообщи результат.` При запросе сетевого доступа согласовать только этот запуск.

## Поведение
Модель выбирается строго из двух ID; переключение на резервную выполняет Codex при допустимом сбое, не скрипт. Внешнему агенту передаётся только текстовое вложение. Шлюз создаёт отдельную временную папку, локальную конфигурацию запретов инструментов и вызывает CLI без --auto. Никаких автоматических правок, установки пакетов, Git push, платных моделей или чтения дерева проекта. Ответ — непроверенный текст. Ограничение запроса 30 КБ, таймаут 180 секунд, максимум 1 МБ вывода. На Windows завершение дочерних процессов при таймауте не гарантировано: при зависании остановить запуск и не повторять автоматически. Источник тарифа и модель нужно перепроверять перед новой рабочей сессией.

## Ограничения проверки
Скрипт подготовлен по документации OpenCode v2. Локальная проверка синтаксиса и имитация CLI не заменяют проверку на Windows с реальным OpenCode. Не гарантируется отсутствие вспомогательных запросов CLI или изменений тарифа. Пакет не является системой предотвращения утечек; обезличивание и проверка эффективных политик обязательны. Gemini не включён: сохранённая авторизация Google не подтверждает условия оплаты.

Документация: https://opencode.ai/docs/cli/commands/ ; https://opencode.ai/docs/permissions ; https://opencode.ai/docs/policies ; https://opencode.ai/docs/console/models/ .
