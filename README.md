# 🎓 Электронный журнал и система кураторского учета УО «ВГТК»

Прототип современной информационной системы для Витебского государственного технического колледжа (ВГТК). Предназначен для автоматизации учебного процесса, ведения электронных журналов преподавателями, почасового учета пропусков и формирования отчетности кураторов групп.

---

## 🚀 Основной стек технологий

* **Frontend:** React (Vite)
* **Стилизация:** Tailwind CSS v4
* **Иконки:** Lucide React
* **Маршрутизация:** React Router DOM
* **Хранение данных:** localStorage (полноценная клиентская база данных без необходимости настройки бэкенда)

---

## ✨ Ключевой функционал системы

### 1. 👨‍🏫 Дашборд и расписание преподавателя
* **Умный виджет расписания на «Сегодня / Завтра»**: отображает реальную сетку звонков ВГТК (пары по 2 академических часа со сдвоенными уроками, одиночные уроки и обеденный перерыв)[cite: 3, 4, 5].
* **Парсинг аудиторий**: автоматическое распознавание деления на подгруппы (например, формат аудитории `308/309` сигнализирует о параллельной практике).
* **Контроль хронологии дат**: защита от случайного создания занятий задним числом с предупреждающим модальным окном.

### 2. 📖 Журнал успеваемости и посещаемости
* **Почасовой учёт**: пара состоит из 2 академических часов (2 отдельные клетки в колонке даты), одиночный урок — из 1 часа. 1 отметка «Н» в клетке равна ровно 1 часу пропуска.
* **Изоляция подгрупп (RBAC / ACL)**: главный преподаватель видит всю группу и сводку оценок второй подгруппы, а второй преподаватель имеет доступ на редактирование исключительно своей подгруппы.
* **Модуль учёта сданных ЛАБ и ПР**: настраиваемая сетка с галочками и шкалой прогресса сдачи лабораторных и практических работ по каждому предмету.
* **Ведомость тем и ДЗ**: встроенный блок для учёта пройденных тем лекций и домашних заданий.

### 3. 📋 Кураторский дашборд и «Форма №6»
* **Сводная аналитика**: средний балл группы, общее количество пропусков и автоматическое выявление учащихся в «зоне риска».
* **Интерактивная ведомость «Форма №6»**: автоматический сбор пропусков (`Н`) из всех предметных журналов[cite: 2].
* **Инструмент быстрой разметки (штамп)**: простановка причин пропусков в один клик (**Б** — больничный, **О** — объяснительная, **З** — заявление, **К** — мероприятия, **Н/У** — неуважительные, **Сп** — свободное посещение)[cite: 2].
* **Экспорт в Word (`.doc`)**: генерация готовой официальной ведомости в альбомной ориентации с чистыми часами в клетках дней и автоматическим суммированием по столбцам[cite: 2, 3].

### 4. 👨‍🎓 Либимый кабинет учащегося
* **Дневник оценок**: просмотр текущих оценок и среднего балла по каждому предмету в реальном времени.
* **Контроль сдачи работ**: личный статус сдачи всех лабораторных и практических.
* **Личная посещаемость**: календарная сетка пропусков за месяц, синхронизированная с кураторской ведомостью[cite: 2].
