# Визуальная система

Использовать существующие токены journal.css: --paper #faf9f5, --card #fffefa, --ink #222c29, --muted #5c6861, --green #204f40, --soft #e9eee6, --line #cdd3c9, --accent #a4422b; тёмные значения уже есть. Добавлять семантические токены статусов, фокуса, отступов по необходимости без массовой перекраски. Системный Segoe UI/Arial; не грузить внешний шрифт. Академический serif можно оставить в редких акцентных заголовках.

- Верхняя панель — бренд, кабинет/роль и тема. Внутри разделов — компактные вкладки/контекстные действия. Не дублировать навигацию. Учащийся на мобильном — нижние вкладки, с отступом safe-area.
- Рабочая таблица — визуально плотная, фиксированные ФИО и заголовки, читаемая активная ячейка. Скролл локальный, не всей страницы. На смартфоне основная операция — модальное окно занятия; таблица остаётся доступной.
- Минимум декора, умеренные скругления, без лишних градиентов, анимаций и карточек ради карточек. Цвет не единственный индикатор состояния. Видимый фокус, понятные подписи, aria-атрибуты, управление клавиатурой, reduced-motion. На телефоне интерактивные элементы по возможности не менее 44×44 CSS px.
- Проверять 360, 390, 768, 1280, 1920 CSS px, обе темы; нет горизонтального скролла всего документа (таблица/официальная форма — отдельные области).
