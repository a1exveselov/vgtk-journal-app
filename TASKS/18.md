## Реализация
- Manifest с name/short_name, start_url/scope относительно deployment, standalone, theme/background, иконки 192/512. Генерировать иконки из существующего бренда только если доступен локальный инструмент, иначе запросить готовые. Не добавлять пакеты.
- SW только при production/secure context: кэшировать versioned статические ресурсы приложения, не запросы API/персональные данные, не внешние ресурсы. Network-first навигация, fallback оболочки при корректном кэше; обновление версии/очистка только своих cache keys, без принудительного reload с черновиком. Если безопасную стратегию без build manifest нельзя реализовать в разрешённых файлах — остановиться, запросить разрешение на конфиг/плагин.
- Установка там, где поддерживается браузером; не обещать offline-редактирование или синхронизацию. Не утверждать готовность к реальным данным.

## Критерии приёмки
- Manifest валиден, приложение устанавливается на поддерживаемом браузере через HTTPS/localhost; прямой URL маршрута требует SPA fallback хоста.
- В DevTools Cache Storage нет API/личных данных; обновление не теряет черновик; нет SW в dev.
- Проверить Android Chromium и iOS Safari вручную, отметить неподдерживаемые функции.
