## Реализация
- Вынести загрузку/сохранение vgtk_students, vgtk_lessons, vgtk_grades, vgtk_form6_overrides, vgtk_works_config_by_subject, vgtk_works_completion_by_subject, vgtk_works_cross_marks в storage/repository; theme оставить отдельно. API пока локальный; не вводить fetch или React Query.
- Единые defaults из mock/существующих конфигов. Демоданные только при отсутствующем ключе; пустые валидные массивы/объекты не заменять; не дописывать mock db/web при каждом чтении. Нормализация старых hourIndex/subjectId только когда однозначна по существующему контракту; не угадывать группу/год.
- Сохранить ключи и shape. Защитить чтение/запись от ошибок JSON/квоты; повреждённый ключ не перезаписывать автоматически, показать сообщение; не выдавать несохранённое за сохранённое. Одна модель чтения для трёх кабинетов, без независимого подмешивания демо.
- Синхронизация при повторном открытии и storage-событии; не внедрять серверные права. Минимальный контракт repository с read/write и структурированным результатом ошибки.

## Критерии приёмки
- Пустой массив после reload остаётся пустым; отсутствующий ключ даёт демо.
- Повреждённый JSON остаётся нетронутым; ошибка видима.
- Одна оценка, причина и статус читаются одинаково во всех кабинетах.
- Тесты отсутствующего/пустого/невалидного значения, ошибок записи; существующие ключи сохранены.
