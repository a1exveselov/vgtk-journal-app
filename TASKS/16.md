## Реализация
- Mobile-first: главная, оценки, работы, посещаемость/расписание через компактные вкладки (нижняя навигация на телефоне, контекстные вкладки на desktop). Сохранить темы/ДЗ и расписание today/tomorrow, текущий демо-выбор учащегося пометить как демонстрационный.
- Последние отметки сортировать по дате урока, если нет createdAt — не утверждать время выставления; динамика успеваемости из общего агрегатора; список несданных/доработок, без просрочки при отсутствии срока. Не считать отсутствующего ученика по fallback без явного выбора.
- Адаптация 360/390/768/1280, safe-area, доступные кнопки, таблицы в локальных scroll областях.

## Критерии приёмки
- Оценки/работы/посещаемость совпадают с журналом/куратором; темы и ДЗ не потеряны.
- Нижняя панель не перекрывает контент; обе темы, длинные названия, пустые данные.
- Режим учащегося не содержит редактирования учебных данных; демо не выдаётся за авторизацию.
