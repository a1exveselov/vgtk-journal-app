# Инварианты предметной области (снимок и ограничения)

- Пара — 2 академических часа с отдельными ячейками; одиночное занятие — 1. Ключ отметки: lessonId + studentId + hourIndex (старые записи без hourIndex трактуются как 1). Н — ABSENT, grade=null; числовая отметка — PRESENT. Удаление оценки не означает присутствие.
- Оба листа дисциплины одной группы могут показывать общие занятия; разграничение по подгруппе не равно двум независимым журналам. Код сейчас разрешает чужую подгруппу после предупреждения и записывает isCrossSubgroup/markedBySubgroup/markedByRole; правила D1 не утверждены. При изменении урока сохранить createdByMain; при создании устанавливать из контекста листа.
- Причины формы №6: Б, О, З, К (уважительные по текущему коду), Н/У, Сп (свободное посещение, ноль часов). Исходные Н не переписывать при уточнении куратора. Ручная корректировка и сброс к журналу — отдельные действия. Официальный экспорт сейчас HTML с расширением .doc, альбомная ориентация; не менять формат без согласования.
- Модель работ сейчас ключ subjectId_studentId_workId, конфиг по предмету, true/false; миграция трёх статусов должна обновлять преподавателя и учащегося совместно. Предмет без сроков сдачи не даёт просроченности.
- Расписание только today/tomorrow; одиночные часы, пары, перерыв, аудитории вида 308/309 и подгруппы не терять. Моки расписания — не реальный источник. Парсер сайта — вне данного фронтенд-плана.
- Прототип содержит демопрофиль, переключение кабинетов и выбор учащегося, а не настоящую авторизацию. Нельзя заявлять безопасность/готовность к эксплуатации с реальными персональными данными.
